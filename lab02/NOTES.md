Рабочая папка - "черновик" или рабочий стол, это те файлы, которые мы редактируем
индекс - промежуточный этап, где формируешь работу перед сохранением
коммит - сохраненная версия проекта

git - локальная версия
github - облачная платформа

diff показывает разницу между рабочей папкой и индексом

diff --staged разницу между индексом и последним коммитом


status - показывает текущие изменения

Ветки

ветка - независимая линия разработки, позволяет делать изменения, не трогая оснавную работу

что происходит при новом коммите ?
ветка- указатель последнего коммита, когда делаем новый коммит, указатель переезжает и начинает указывать на только созданный снимок
что делает слияние ?
она переносит изменения из одной ветки в другую
